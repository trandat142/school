# Lệnh biên dịch và chạy Java

## 1. Biên dịch file Java

```bash
javac TenFile.java
```

Ví dụ:

```bash
javac BaiThucHanhWhile.java
```

Sau khi biên dịch, Java tạo file:

```text
BaiThucHanhWhile.class
```

## 2. Chạy chương trình

```bash
java TenFile
```

Ví dụ:

```bash
java BaiThucHanhWhile
```

Lưu ý: khi chạy không ghi `.java` hoặc `.class` ở cuối.

Đúng:

```bash
java BaiThucHanhWhile
```

Sai:

```bash
java BaiThucHanhWhile.java
java BaiThucHanhWhile.class
```

## 3. Nộp bài

Nộp file:

```text
BaiThucHanhWhile.java
```

Không nộp file:

```text
BaiThucHanhWhile.class
```

Vì thầy cô cần chấm code nguồn.
