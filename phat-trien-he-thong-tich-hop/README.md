## Quy ước của môn

- `online/`: bài học online, ghi chú và demo code.
- `offline/`: bài thực hành offline, đề lab và bài làm.
- `tai-lieu/`: slide, PDF và tài liệu gốc.

## Ghi chú

Các folder offline hiện tại chỉ có `README.md` để giữ thư mục. Khi có bài offline thật, thêm đề bài, source code và ghi chú vào đúng buổi.
