# Câu hỏi ôn tập buổi 01

## 1. Lập trình là gì?

Lập trình là lập ra trình tự các bước, viết thành mã lệnh để máy tính thực hiện một bài toán.

## 2. Giải thuật là gì?

Giải thuật là cách giải quyết bài toán được mô tả rõ ràng theo từng bước.

Ví dụ:

- Tìm kiếm
- Sắp xếp
- Tìm số lớn nhất
- Tìm số nhỏ nhất

## 3. Vì sao cần học cấu trúc dữ liệu và giải thuật?

Vì đây là nền tảng giúp xử lý dữ liệu hiệu quả hơn.

Một chương trình tốt không chỉ chạy đúng mà còn cần chạy nhanh và tiết kiệm tài nguyên.

## 4. ISA là gì?

ISA là Instruction Set Architecture, tức kiến trúc tập lệnh.

Đây là tập lệnh mà CPU hiểu và thực thi được.

## 5. CPU gồm những thành phần nào?

Các thành phần chính:

- CU
- ALU
- Tập thanh ghi
- Bus interface
- Cache

## 6. CU là gì?

CU là Control Unit, tức khối điều khiển.

Nó điều khiển quá trình đọc, giải mã và thực thi lệnh.

## 7. ALU là gì?

ALU là Arithmetic Logic Unit.

Nó xử lý phép toán số học và logic như cộng, trừ, so sánh, AND, OR.

## 8. RAM là gì?

RAM là bộ nhớ tạm, lưu dữ liệu và chương trình đang chạy.

Dữ liệu trong RAM sẽ mất nếu tắt máy mà chưa lưu.

## 9. Bus là gì?

Bus là đường truyền dữ liệu giữa CPU, RAM và các thiết bị khác.

## 10. Process và Thread khác nhau thế nào?

Process là tiến trình, tức một chương trình đang chạy.

Thread là luồng xử lý nhỏ hơn bên trong process.

Một process có thể có nhiều thread.

## 11. Java hoạt động như thế nào?

Quy trình:

```text
.java -> javac biên dịch -> .class -> JVM thực thi
```

## 12. JDK, JRE, JVM khác nhau thế nào?

JDK dùng để phát triển Java, gồm JRE và compiler.

JRE dùng để chạy chương trình Java.

JVM thực thi bytecode `.class`.

## 13. Vì sao Java có thể chạy trên nhiều hệ điều hành?

Vì Java được biên dịch thành bytecode `.class`.

Bytecode này chạy trên JVM. Máy nào có JVM phù hợp thì có thể chạy chương trình Java.

## 14. Lỗi logic là gì?

Lỗi logic là lỗi khiến chương trình vẫn chạy nhưng kết quả sai.

Đây là lỗi nguy hiểm vì máy không luôn báo lỗi rõ ràng.
