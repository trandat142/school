# Bài 4.1 - Phân tích Session & Trả lời câu hỏi

## Đề bài

Cho hai trang PHP (`session.php` và `dangxuat.php`), phân tích lỗi và hoàn thiện.

Gợi ý: Tạo trang `ketqua.php` và xuất nội dung trả lời lên giao diện web.

## Cách chạy

1. Mở trang session:
   ```text
   http://localhost/buoi-4/bai-4-1-phan-tich-session-dangxuat/session.php
   ```
2. Mở trang kết quả trả lời:
   ```text
   http://localhost/buoi-4/bai-4-1-phan-tich-session-dangxuat/ketqua.php
   ```
