# Bài 4.1 - Phân tích Session & Hoàn thiện Đăng xuất

## Mục tiêu
- Trả lời các câu hỏi phân tích lỗi cú pháp và hành vi thực thi của 2 trang `session.php` và `dangxuat.php`.
- Xây dựng trang `ketqua.php` hiển thị kết quả phân tích trực quan.
- Cung cấp mã nguồn hoàn chỉnh đã sửa lỗi của `session.php` và `dangxuat.php`.

## Cách chạy
1. Xem trang demo Session đã sửa lỗi:
   ```text
   http://localhost/buoi-4/bai-4-1-phan-tich-session-dangxuat/session.php
   ```
2. Xem trang báo cáo kết quả phân tích:
   ```text
   http://localhost/buoi-4/bai-4-1-phan-tich-session-dangxuat/ketqua.php
   ```
