# Bài 2.5 - Trang đăng ký có CSS layout

## Mục tiêu

Tạo trang đăng ký thông tin có bố cục CSS gồm:

- Header
- Menu bên trái
- Nội dung bên phải
- Footer

Bài này gồm 2 file:

- `dangky.php`
- `style.css`

## Cách chạy

```text
http://localhost/buoi-2/bai-2-5-dang-ky-css-layout/dangky.php
```

## File cần xem

- `style.css`
- `dangky.php`

Trong code đã có comment giải thích từng dòng quan trọng.
