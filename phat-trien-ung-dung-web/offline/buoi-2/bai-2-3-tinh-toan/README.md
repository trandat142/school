# Bài 2.3 - Trang tính toán

## Mục tiêu

Tạo trang tính toán cho người dùng nhập 2 số, chọn phép tính và hiển thị kết quả.

Bài này gồm 2 file:

- `clspheptinh.php`: class chứa các hàm tính toán.
- `tinhtoan.php`: giao diện nhập số và xử lý phép tính.

## Cách chạy

```text
http://localhost/buoi-2/bai-2-3-tinh-toan/tinhtoan.php
```

## File cần xem

- `clspheptinh.php`
- `tinhtoan.php`

Trong code đã có comment giải thích từng dòng quan trọng.
