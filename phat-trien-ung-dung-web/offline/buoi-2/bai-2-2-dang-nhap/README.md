# Bài 2.2 - Tạo trang đăng nhập

## Mục tiêu

Tạo trang `login.php`.

Nếu nhập đúng:

- Email: `abc@gmail.com`
- Password: `123456`

thì hiển thị:

```text
Chúc mừng đăng nhập thành công!
```

Nếu nhập sai thì hiển thị:

```text
Đăng nhập thất bại
```

## Cách chạy

```text
http://localhost/buoi-2/bai-2-2-dang-nhap/login.php
```

## File cần xem

- `login.php`

Trong code đã có comment giải thích từng dòng quan trọng.
