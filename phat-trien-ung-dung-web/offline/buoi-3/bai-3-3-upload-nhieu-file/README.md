# Bài 3.3 - Upload đồng thời nhiều file (Multiple Upload)

## Mục tiêu
- Cho phép người dùng chọn và tải lên nhiều file cùng lúc bằng thuộc tính `multiple` và `name="file[]"`.
- Duyệt qua từng file bằng vòng lặp `for`.
- Hiển thị danh sách kết quả dưới dạng các thẻ (card) nằm ngang.

## Cách chạy
Mở trình duyệt:
```text
http://localhost/buoi-3/bai-3-3-upload-nhieu-file/upload.php
```
