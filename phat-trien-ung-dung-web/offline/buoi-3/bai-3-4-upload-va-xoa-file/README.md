# Bài 3.4 - Quản lý Upload và Xóa file đã tải lên

## Mục tiêu
- Xây dựng form upload file lên thư mục `upload/`.
- Quét và liệt kê danh sách tất cả các file hiện có trên server bằng `scandir()`.
- Tạo nút **Xóa** sử dụng thẻ `<input type="hidden">` để truyền đường dẫn và dùng hàm `unlink()` để xóa file vật lý trên máy chủ.

## Cách chạy
Mở trình duyệt:
```text
http://localhost/buoi-3/bai-3-4-upload-va-xoa-file/quanlyfile.php
```
