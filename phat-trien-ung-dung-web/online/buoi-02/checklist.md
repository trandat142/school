# Checklist buổi 02

## Việc cần làm

- [ ] Làm demo cấu trúc điều kiện bằng `if/else`.
- [ ] Làm demo cấu trúc điều kiện bằng `switch`.
- [ ] Chạy thử trên localhost.
- [ ] Xem lại video demo giảng viên gửi trong group.
- [ ] Đọc lại phần biến trong PHP.
- [ ] Đọc lại phần nối chuỗi bằng dấu `.`.
- [ ] Ghi nhớ `switch` phải có `break`.

## Môi trường

- [ ] WAMP Server chạy được.
- [ ] XAMPP chạy được nếu dùng XAMPP.
- [ ] Mở được localhost.
- [ ] Tạo được file `.php`.

## Cần nhớ

- [ ] PHP dùng `<?php ... ?>`.
- [ ] Dùng `echo` để xuất dữ liệu.
- [ ] Biến bắt đầu bằng `$`.
- [ ] PHP phân biệt hoa thường.
- [ ] Nối chuỗi bằng dấu `.`.
