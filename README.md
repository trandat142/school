# School

Repo lưu tài liệu, ghi chú và source code các môn học.

## Danh sách môn học

- [Phát triển hệ thống tích hợp](phat-trien-he-thong-tich-hop)

## Quy ước chung

- Mỗi môn có `README.md` riêng để vào nhanh tài liệu và từng buổi học.
- `tai-lieu/`: slide, PDF, đề bài, tài liệu gốc.
- `online/`: bài học online, ghi chú, demo code trên lớp.
- `offline/`: bài thực hành offline, đề lab, bài làm, file nộp.
