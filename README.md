## Quy ước lưu trữ

- `online/`: bài học online, ghi chú, demo code trên lớp.
- `offline/`: bài thực hành offline, đề lab, bài làm, file nộp.
- `tai-lieu/`: slide, PDF, tài liệu gốc của môn.

## Ghi chú

Các folder offline hiện tại chỉ có `README.md` để giữ thư mục. Khi có bài offline thật, thêm đề bài, source code và ghi chú vào đúng buổi.
